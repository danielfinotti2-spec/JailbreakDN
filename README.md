# Cofre de Prompts · @euodeene

Biblioteca estática em React + Vite. Os arquivos fornecidos foram organizados em categorias por modelo-alvo aproximado e cada item pode ser aberto, copiado ou baixado individualmente com seu nome de arquivo original.

## Rodar localmente
```bash
npm install
npm run dev
```

## Gerar versão para publicar
```bash
npm run build
npm run preview
```

A pasta `dist/` gerada pelo build pode ser publicada em hospedagens estáticas como Vercel, Netlify ou GitHub Pages. Não há backend nem banco de dados.

**Nota:** as categorias indicam o modelo-alvo aparente, não uma garantia de compatibilidade. Os arquivos originais foram preservados.
